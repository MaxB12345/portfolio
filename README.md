# portfolio

A personal portfolio site: plain HTML, CSS and JavaScript, no build step. Served by GitHub Pages.

## Run locally

Open `index.html` in a browser, or serve the folder:

```sh
python3 -m http.server 8000
```

## Edit content

Everything lives in `index.html`. Placeholders to replace are marked `Your Name`, `Company Name`, `University Name`, `School Name`, `20XX`, `00` and `X` (A Level grades), plus the GitHub, LinkedIn and email links.

## Deploy

In the repo on GitHub, go to **Settings → Pages**, set **Source** to "Deploy from a branch", pick `main` and `/ (root)`, and save. The site appears at https://maxb12345.github.io/portfolio/ about a minute after each push to `main`.
